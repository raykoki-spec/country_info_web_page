# Country Info

A html file that looks up basic fears of a country by combining info from two different APIs(api.worldbank.org and flagcdn.com). 

## What It Does

- Asks the user to type in the country.
- Shows the flag, capital city, region of country's location and population.
- It has a clear error message.
- Has a responsive layout that can work on phone. 



## Setup

```bash
pip install -r requirements.txt
```

## Usage

```html
Save the file as fetch.html
Open it in your preffered browser
```

## Sample Output

```
Flag of KenyaKenya
Capital: Nairobi

Region: Sub-Saharan Africa

Population: 57,532,493 (2025)
```
